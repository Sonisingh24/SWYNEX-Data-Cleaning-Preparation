This project focuses on cleaning and preparing sales data for analysis.


## Work Performed
- Removed duplicate records
- Handled missing values
- Cleaned and standardized data
- Checked data consistency
- Prepared the dataset for analysis

## Tools Used
- Excel
- Python
- Pandas

## Dataset
The cleaned dataset is available in this repository as:

`sales_data_cleaned.csv`

## Objective
The main objective of this project is to transform raw sales data into a clean and analysis-ready dataset.
